# BiliLocal 图标

使用内置 image_gen 工具生成；分类：logo-brand。原图保留透明背景，build-icon.ps1 仅缩放并封装为多尺寸 ICO（16、24、32、48、64、128、256），未重绘图像。

项目资源：BiliLocal.png、BiliLocal.ico。图标用于 Windows EXE、窗口及任务栏。

最终生成提示词：

Create ONE finished Windows desktop application icon for a Bilibili video downloader called BiliLocal. Square 1024x1024 PNG with true transparent alpha background outside the symbol. Visual style inspired by Bilibili's friendly rounded television mascot and signature bright pink (#FB7299), but an original downloader symbol with no lettering and no official wordmark. A bold, simple flat pink TV-shaped silhouette, two short antennae angled outward on top, softly rounded screen corners, two tiny feet. Inside the TV use a clean large white downward arrow landing in a white download tray, centered and unambiguous; this download arrow is the main negative-space feature, do not put eyes or a face behind it. High contrast, very few shapes, thick geometry, crisp smooth edges, immediately readable at 16x16 and 32x32. Front-facing, perfectly centered, balanced proportions, occupy about 86% of canvas, leave 7% transparent margin. Flat vector-like rendered raster art; no gradients, no 3D, no shadows, no reflections, no photographs, no rounded square backdrop, no text, no watermark. Deliver only the single icon, not a mockup or grid.
